# Web Chef — портфолио Арсения Асянова

Сайт-портфолио: кто я, работы со ссылками на живые версии и разбор каждой работы.
Статический HTML/CSS/JS без сборщика, выкладывается на GitHub Pages как есть.

## Что где

| Путь | Что это |
| --- | --- |
| `index.html` | Главная: фото и «кто я», список работ, блок на каждую работу, контакты |
| `cases/<имя>/index.html` | Разбор работы: для кого, что сделано, решения со ссылками на коммиты, как проверить |
| `assets/css/site.css` | Токены (цвета, шрифты, кривые движения) и общие компоненты |
| `assets/css/case.css` | Стили страниц разбора |
| `assets/js/site.js` | Появление блоков, плавный переход к разделам, кнопка «Остановить анимацию», просмотр скриншотов |
| `assets/js/hero-field.js` | WebGL-поле на первом экране |
| `assets/vendor/three-hero.min.js` | Урезанная сборка three.js 0.186 только под сцену |
| `assets/img/` | Фото и скриншоты, по два размера каждого |
| `tools/` | Подготовка картинок, сборка three.js, локальный сервер |

## Как добавить работу

1. **Скриншоты.** Сохраните PNG первого экрана (ширина 1440) и телефона, затем:
   ```
   powershell -ExecutionPolicy Bypass -File tools/resize-images.ps1 -Src <папка с PNG> -Dst assets/img/cases/<имя> -Widths "800,1440"
   powershell -ExecutionPolicy Bypass -File tools/resize-images.ps1 -Src <папка с PNG телефона> -Dst assets/img/cases/<имя> -Widths "393,786"
   ```
   Размеры исходников попадут в `sizes.json` — из него берутся `width` и `height` для разметки.
2. **Главная.** В `index.html` есть комментарий над разделом «Работы»:
   - строка в списке `.index` — номер, название, адрес и ссылка «Открыть»;
   - блок `article.exhibit` — скопируйте соседний и поменяйте тексты, ссылки и пути к скриншотам;
   - запись в `#gallery-data` внизу страницы — скриншоты для просмотрщика (ключ совпадает с `data-gallery`).
   Номера идут сверху вниз: 01, 02, 03…
3. **Разбор** (по желанию) — скопируйте папку из `cases/`, поменяйте тексты и добавьте ссылки
   «← Разбор / Разбор →» в соседних разборах.

Пишите только то, что можно проверить по сайту или репозиторию: без выдуманных цифр и отзывов.

## Локальный просмотр

```
node tools/serve.mjs
```

Откроется `http://localhost:4600/web-chef-portfolio/` — тот же путь, что на GitHub Pages.

## Сцена на первом экране

Поле точек в перспективе: дышит, под курсором поднимается линзой и краснеет, по касанию
расходится волна. Один вызов отрисовки, без постобработки. Скрипт three.js грузится
только после загрузки страницы и только если сцена действительно запустится.

Вместо сцены показывается статичный фон (точки на CSS), если:
- включено «уменьшить движение»;
- включена экономия трафика;
- у устройства ≤2 ядер или ≤2 ГБ памяти;
- WebGL недоступен или работает программно;
- сцена не держит частоту кадров даже на низком качестве.

Качество подстраивается само: не держим ~54 кадра — меньше точек и ниже плотность пикселей,
на низком качестве не держим ~36 — сцена гаснет. Кнопка «Остановить анимацию» замораживает
поле и плашки, выбор запоминается.

Параметры адреса для проверки: `?webgl=0`, `?gl=force`, `?tier=high|mid|low`, `?governor=0`,
`?debug=1` (FPS и счётчики), `?view=height|lens|lattice`, `?cam=near|far`,
`?t=4.2` (один кадр без анимации), `?px=0.5&py=0.6`, `?ripple=0.8`.

Пересобрать three.js после изменения списка импортов в `tools/three-hero-entry.js`:

```
npm install
npm run build:three
```
